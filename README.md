# T-SQUARE — สมุดงาน & นิสัย

## วิธีใช้งานผ่าน GitHub Pages

1. สร้าง repository ใหม่บน GitHub (Public)
2. อัปโหลดไฟล์ `index.html` เข้าไปใน repo (Add file → Upload files → Commit)
3. ไปที่ Settings → Pages → Source เลือก branch `main`, folder `/ (root)` → Save
4. รอสักครู่ จะได้ลิงก์ประมาณ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`
5. เปิดลิงก์นั้นบนมือถือ (Chrome/Safari) → กดปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"

## ข้อมูล
ข้อมูลทั้งหมด (การบ้าน, นิสัย, ตารางออกกำลังกาย) เก็บไว้ในเบราว์เซอร์ของอุปกรณ์นั้น (localStorage)
ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ที่ไหน และไม่ sync ข้ามอุปกรณ์

ใช้ปุ่ม "⇄ ย้าย/สำรองข้อมูล" ในแอปเพื่อคัดลอกข้อมูลไปสำรองไว้ที่อื่น หรือย้ายไปเปิดอีกเครื่องได้
