# T-SQUARE — สมุดงาน & นิสัย

## โครงสร้างไฟล์ (แบบเดียวกับแอปจริง)
- index.html — ตัวแอป
- manifest.json — ข้อมูลแอปสำหรับติดตั้งเป็น PWA (ชื่อ, ไอคอน, สีธีม)
- service-worker.js — ทำให้แอปใช้งานออฟไลน์ได้ และอัปเดตตัวเองอัตโนมัติเมื่อมีอินเทอร์เน็ต
- icon-192.png, icon-512.png — ไอคอนแอปสำหรับ Android/PWA
- apple-touch-icon.png — ไอคอนแอปสำหรับ iOS

## วิธีติดตั้งขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub (Public)
2. อัปโหลดไฟล์ทั้งหมดในนี้ (Add file → Upload files → ลากทุกไฟล์เข้าไปพร้อมกัน → Commit)
   **สำคัญ:** ไฟล์ทั้งหมดต้องอยู่โฟลเดอร์เดียวกัน (root) ห้ามอยู่คนละโฟลเดอร์
3. ไปที่ Settings → Pages → Source เลือก branch `main`, folder `/ (root)` → Save
4. รอสักครู่ จะได้ลิงก์ประมาณ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`
5. เปิดลิงก์บนมือถือ (Chrome/Safari) → กดปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"

## อัปเดตแอปครั้งต่อไป
แก้ไฟล์ index.html ใหม่ → อัปโหลดทับไฟล์เดิมใน repo → Commit
service-worker.js จะดึงเวอร์ชันล่าสุดให้อัตโนมัติทุกครั้งที่เปิดแอปตอนมีเน็ต
(ไม่ต้องลบไอคอนหน้าจอโฮมแล้วเพิ่มใหม่อีกต่อไป)

## ข้อมูลผู้ใช้
ข้อมูลทั้งหมด (การบ้าน, นิสัย, ตารางออกกำลังกาย) เก็บไว้ในเบราว์เซอร์ของอุปกรณ์นั้น (localStorage)
ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ที่ไหน และไม่ sync ข้ามอุปกรณ์
ใช้ปุ่ม "⇄ ย้าย/สำรองข้อมูล" ในแอปเพื่อคัดลอกข้อมูลไปสำรองไว้ที่อื่น หรือย้ายไปเปิดอีกเครื่องได้
